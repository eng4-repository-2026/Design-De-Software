# Registro de feedback e refinamento

| Feedback | Impacto | Decisão | Artefato alterado |
|---|---|---|---|
| Exemplo: usuário quer aviso apenas em mudanças relevantes | Observer pode filtrar eventos | criar política de notificação | diagrama + código + ADR |

## Regra
Feedback não deve ser incorporado automaticamente. O grupo deve justificar se aceita, adapta ou rejeita, registrando consequência.
